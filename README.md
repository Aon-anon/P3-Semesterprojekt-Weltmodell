# Projektdemonstration – P3 WS 25/26 IMD h_da

Dieses Repository enthält den gesamten Quellcode der Weltmodell-Website.
Im Ordner `dist` liegt bereits eine für die Produktion kompilierte Version der Anwendung bereit.
Für das lokale Ausführen des Prototyps wird Node.js benötigt: https://nodejs.org/en/download.

Die Anwendung ist außerdem als GitHub Pages unter https://Aon-anon.github.io/P3-Semesterprojekt-Weltmodell verfügbar.

**Ausführung**

1.  Öffnen Sie ein Terminal im Hauptverzeichnis des Projekts.

2.  Führen Sie folgenden Befehl aus:

    `npx serve -s dist`

3.  Das Terminal gibt anschließend eine localhost-URL aus.
    Diese kann entweder mit Strg + Klick geöffnet oder manuell in den Browser kopiert werden.
